# Gold Clicker - Игра кликер для добычи золота

Мобильная игра-кликер на React Native/Expo с тематикой добычи золота.

## 📋 Требования

- Node.js 18+
- npm или yarn
- Expo CLI

## 🚀 Установка и запуск

```bash
# Перейдите в директорию проекта
cd Игра_кликер

# Установите зависимости
npm install

# Запустите проект
npm start

# Для запуска на iOS
npm run ios

# Для запуска на Android
npm run android

# Для запуска в веб-браузере
npm run web
```

## 🎮 Особенности игры

### Архитектура
- **Паттерн Observer (Наблюдатель)**: Интерфейс обновляется только при изменении данных, а не в каждом кадре
- **Object Pooling**: Переиспользование объектов для всплывающих чисел, что предотвращает лаги при частых кликах
- **Экспоненциальная экономика**: Стоимость улучшений рассчитывается по формуле `Price = BaseCost × (Multiplier ^ Level)`

### Функционал
- **Главная кнопка**: Добыча золота с визуальным фидбеком и анимацией
- **Система прокачки**:
  - Сила клика (Click Power) - увеличивает количество золота за клик
  - Авто-клик (Passive Income) - автоматическая добыча золота раз в секунду
- **Магазин**: 5 улучшений с возрастающей ценой:
  - ⛏️ Кирка (+1 к силе клика)
  - 👷 Шахтёр (+1 золота в секунду)
  - 🚜 Буровая установка (+5 золота в секунду)
  - 🧨 Динамит (+5 к силе клика)
  - 🏭 Золотой рудник (+20 золота в секунду)
- **Сохранение прогресса**: Автоматическое сохранение каждые 10 секунд и при выходе
- **Всплывающие числа**: Анимированные эффекты при клике с использованием Object Pooling

### Оптимизация
- Форматирование больших чисел (K, M, B, T для тысяч, миллионов, миллиардов, триллионов)
- Использование `useNativeDriver` для анимаций
- Реактивное обновление UI через события

## 🎨 Дизайн

- Тёмная тема с золотыми акцентами
- Анимированная кнопка с эффектом нажатия
- Индикаторы дохода от кликов и авто-добычи
- Карточки улучшений с индикацией доступности

## 💾 Сохранение прогресса

Прогресс сохраняется автоматически:
- Каждые 10 секунд
- После покупки улучшения
- При выходе из приложения

Также доступно ручное сохранение через кнопку "Сохранить".

## 🔧 Технические детали

### Типы данных
- Все числовые значения используют тип `number` (double precision)
- Поддержка чисел до триллионов с форматированием

### События (GameEvents)
- `GOLD_CHANGED` - изменение количества золота
- `CLICK_POWER_CHANGED` - изменение силы клика
- `AUTO_CLICK_CHANGED` - изменение авто-дохода
- `UPGRADE_PURCHASED` - покупка улучшения
- `POPUP_CREATED` - создание всплывающего числа
- `GAME_LOADED` - загрузка игры
- `GAME_SAVED` - сохранение игры
